# 수치 근거와 재검증 결과

분석 기준은 원본 가설 노트북이다. 셀 번호는 Markdown을 포함한 전체 셀을 1부터 센다. 보고서 수치를 혼합하지 않는다. 원본 파일명·해시·상세 비교는 저장소 밖 private-review에 보관했다. 최신 게시 수치는 assets/analysis-summary.json의 수정 후 재계산 값이다.

수정 전후 필터 이전 데이터프레임이 동일하고, 공통 관측의 총수익 산식 값은 그대로임을 검증했다. 공통 관측 중 11,260행의 사분면 소속이 바뀌었다. 최신 월 대상은 원래 538행 중 453행을 유지하고 85행이 빠지고 6행이 새로 들어와 459행이 됐다. 따라서 새 수치를 원래 제출 성과처럼 소급하지 않는다.

## 수치 해석

- 금액은 원노트북 추정 산식을 유지한다. 백만원을 억 원으로 표시할 때 100으로 나눈다.
- 비중 분모를 정규 분석군과 극단값 포함 집단으로 구분했다. 관측된 월별 수익을 36개월 고객 수나 고유 기업 수로 바꾸지 않는다.
- p=0.0은 라이브러리의 수치 표현이다. 사람용 문서에서는 정확한 확률 0이 아니라 매우 작은 p-value로 해석한다.
- 수정 후 일반·우수 비교의 명목 유의성은 원본과 다르다. 다만 반복 관측 가능성, 동일 지수로 표본을 구성한 선택 구조, 표본 내 효과 크기를 함께 고려한다.
- 별도 신뢰구간은 산출하지 않았다. 이번에 추가한 효과 크기를 원래 프로젝트에서 보고한 값처럼 쓰지 않는다.
