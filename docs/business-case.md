# 고객관리 제안과 경제성 판단

## 최종 제안

일반 등급 알짜를 무조건 승급하거나 대출을 확대하기보다, 기존 담당자가 거래관계를 점검할 후보로 활용한다. 최신 월 459행은 노트북 산식상 추정 기여 18.92억 원을 가진다. 이 값은 현재 거래의 대략적인 상대 기여를 보는 지표이며 캠페인이 창출할 신규 이익이 아니다.

459행 중 292행은 이미 전담고객이다. ‘기존 평가가 전부 놓친 고객’이라는 주장은 버리고, 관리 우선순위와 상담 주제를 보완한다. 전담고객이 아닌 관측을 무조건 고비용 전담관리로 전환할 근거도 없다.

## 상품 연계 규칙

2024.12 정규 분석군 → 기존 일반 등급 & FAI 낮음 & FPI 높음(459) → 대출 이용(455) → 신용·체크카드 사용금액 모두 0(313).

- 신용카드 개수 양수 157행: 보유 카드의 당월 미이용 사유·결제 수요를 확인하는 이용 재개 파일럿 후보. 한 달 0원만으로 장기 휴면이라고 하지 않는다.
- 신용카드 개수 0인 156행: 카드 수요·기존 거래·적합성을 먼저 확인. 체크카드 보유 여부는 알 수 없으므로 모든 카드 미보유자로 표현하지 않는다.
- 업무 연동안: 은행 내부 고유 고객 ID로 중복을 제거하고 계약 상태·수신 동의·담당자를 확인한 뒤 CRM의 상담 후보 목록으로 연동. 연락·상담·상품 안내는 아직 실행하지 않았다.

디지털 비사용 278행을 그대로 비용 절감 대상으로 삼지 않는다. 이 중 당월 창구 거래가 있는 관측은 10행 미만이다. 채널 건수 자체도 구간 대표값이므로 정확한 처리 비용을 추정하기 어렵다. 미사용이라는 사실만으로 강제 디지털 전환이나 비용 절감 성과를 주장하지 않는다.

## 손익분기 계산: 실제 관측과 가정의 경계

| 입력 | 값 | 성격 |
|---|---:|---|
| 신용카드 보유·당월 카드 미이용·대출 이용 후보 | 157행 | 이번 재분석 관측 |
| 고유 접촉 대상 수 N | 예시에서는 157 | 실제로는 ID로 중복·접촉 가능 여부를 확인해야 함 |
| 접촉비 c | 1인 1,000원 | 설명용 가정, 은행 실제 원가 아님 |
| 추가 활성 고객당 월 순기여 m | 30,000원 | 설명용 가정, 기존 총수익/FPI에서 환산하지 않음 |
| 추가 활성률 Δp | 2/5/10%p | 대조군 대비 차이의 가정, 관측 전환율 아님 |
| 추가 고정비 F | 예시에서는 0원 | 시스템 구축비 등이 있으면 추가 필요 |

1개월 순증 이익 = N×Δp×m−N×c−F.

손익분기 Δp = (N×c+F)/(N×m). 예시에서는 3.33%p다. 2%p이면 −62,800원, 5%p이면 78,500원, 10%p이면 314,000원이다. 소수 기대 활성 수는 기댓값이며 실제 고객 수가 아니다. 단가와 전환율은 합성 시나리오 입력이며 원래 분석 결과를 입증하는 데이터가 아니다.

이 가정에서는 이익 규모가 작을 수 있다. 대규모 개발·일괄 고비용 캠페인을 정당화하기보다 기존 담당자 채널을 이용한 소규모 검증부터 제안한다. 실제 순기여는 혜택·처리·위험 비용과 기존 소비의 이동까지 고려해야 한다. 유지기간 데이터가 없으므로 1개월 결과를 연간/LTV로 확장하지 않았다.

## 실행 검증 설계 — 아직 수행하지 않음

1. 고유 고객 ID와 최소 수개월 이용 이력을 확인해 실제 미활성 대상인지 검증한다. 현재 데이터의 업종·지역 조합으로 임의 ID를 만들지 않는다.
2. 신용카드 유효 상태·상품 적합성·연락 가능 여부를 확인해 확정 대상과 예상 비용을 산출한다. 전담 여부는 기존 접점 선택에 활용한다.
3. 고객 단위로 안내군과 대조군을 무작위 배정하고, 사전에 활성의 정의·관측기간·주평가지표를 정한다. 동일 고객이 두 집단에 섞이지 않게 한다.
4. 주평가지표는 접촉 대상당 1개월 **증분 순기여**로 두고, 보조 지표는 추가 활성률·실제 카드 이용액·불만/해지·캠페인 비용으로 둔다.
5. 대조군 활성률·분산·허용 최소 효과·예산으로 필요한 표본 수와 기간을 산정한다. 157행만으로 충분한 통계적 검정력이 있다고 주장하지 않는다.
6. 실제 순증 이익과 불확실성이 실행 기준을 만족할 때 범위를 확대한다. 효과가 없으면 가설을 수정하거나 중단한다.
