# 분석 방법과 변경 내역

## 지표와 전처리

가설 노트북의 분석 의도를 유지했다. 구간 건수 대표값, 상품 조합, IQR 3배, 로그·Min-Max, 동일 가중치, 중앙값 사분면을 새 모델로 교체하지 않았다. FAI와 FPI는 전체 36개월 정규 분석군에 적합한 후향적 분류이며 미래 예측용 검증 점수가 아니다.

FAI=(규모 평균+빈도 평균+다양성 점수)/3. 규모는 예금·대출·채널·외환·카드 5개, 빈도는 채널·외환 2개, 다양성은 예금·대출·카드·외환 이용 여부의 합/4다. 규모·빈도는 log1p 후 Min-Max, 다양성은 Min-Max를 적용한다.

FPI=(수익기여점수+수익효율점수)/2. 기여점수는 예대마진과 추정 비이자수익의 스케일 점수 평균, 효율점수는 추정 총수익/은행 내 잔액 합계×100의 Min-Max 점수다. 음수가 있는 기여 변수는 전체 최소값만큼 이동한 뒤 log1p를 적용한다.

코드상 총자산은 예금+대출+수익증권+신탁 잔액이다. 퇴직연금 잔액을 다시 더하지 않는다. 기업 재무제표 총자산·법적 중소기업 기준으로 해석하지 않는다.

총수익=대출 잔액×보조 대출금리×0.01−예금 잔액×보조 예금금리×0.01+추정 비이자수익. 후자는 수익증권·신탁·외환·카드 금액과 보조 수수료율의 곱이다. 금리 파일을 추가로 12로 나누지 않는 가설 노트북 산식을 기준으로 했다. 원 메모의 수수료율 월 환산은 잔액형과 거래금액형에 같은 방식으로 적용되어, 실제 계약·거래주기와 맞는지 검증이 필요하다. 예금의 자금조달 가치·운영 비용·신용손실 등을 충분히 반영한 경제적 이익이 아니다.

## 검정 선택과 가정

| 방법 | 목적·선택 이유 | 해석 범위 |
|---|---|---|
| VIF | 지수 후보 변수의 선형 중복성 점검 | 원코드처럼 절편 없이 계산. 인과성·지표 타당성 증거는 아님 |
| Levene(center=median) | 등급별 예대마진/FPI 분산 차이 확인 | 정규성·독립성을 확인하는 검정이 아님 |
| Kruskal–Wallis | 왜도·0이 많은 값의 다집단 순위 비교 | H0는 집단 분포의 동일성. 동일 분포 형태 가정 없이 중앙값만의 검정이라고 하지 않음 |
| Dunn–Bonferroni | 다집단 순위 비교 후 쌍별 비교·다중비교 보정 | 이 절차 내부의 보정이며 모든 탐색 분석 전체를 보정한 것은 아님 |
| Mann–Whitney U | 디지털 이용별 양측 비교, 원래 알짜와 다른 집단의 단측 비교 | 독립 표본·방향성 선택을 고려. 고객 반복 관측으로 명목 p-value만 탐색적으로 보고 |
| 순위 양분상관(추가) | U에서 2U/(n1×n2)−1 산출, 표본 내 순위차 크기 확인 | 양수는 첫 집단의 값이 큰 경향. Dunn의 세 집단 전체 순위와 직접 같은 척도는 아님 |

알파=0.05. 그룹을 만든 지수로 그룹 간 유의성을 확인하는 검정은 독립 성능 검증으로 사용하지 않았다. 전체 기간에 고객 반복 여부를 확인할 ID가 없어 유효 표본 수·독립성은 미확인이다. 동일 월 비교도 ID 유일성 검증을 대체하지 않는다. p>=0.05는 동등성을 증명하지 않는다.

## 원본 오류와 정리 방식

| 원본 셀 | 문제 | 이번 처리 |
|---|---|---|
| 28 | 결측/0잔액 제거 후 인덱스와 boolean mask 인덱스 불일치 | 데이터프레임 인덱스로 mask 생성. 6행 추가 분리 및 후속 결과 변화 공개 |
| 72 | FAI 검정에도 FPI 배열 전달 | FAI 배열로 재계산. 인위적으로 나눈 집단 차이를 모델 우수성으로 해석하지 않음 |
| 100 | 두 Mann–Whitney 결과를 같은 변수에 덮어씀 | 비교별 통계량과 p-value를 서로 다른 집계 키로 저장 |
| 111·113 | 생성하지 않은 총채널거래건수2 참조 | 정의를 추측하지 않고 해당 탐색 분기 제외. 명시된 총채널거래건수 사용 |
| 85·89 | 0분모로 무한대 또는 분모+1 임의 보정 | 건당 실제 수익/비용 근거로 사용하지 않음. 이 비율을 핵심 재분석 지표에서 제외 |
| 96·126 | 제목의 제조업 필터 부재, 금액 축 단위 불일치 | 최신 월 전체 대상, 백만원/억원 단위로 새 집계 그림 제작 |

그 외 입력 경로를 CLI 인자로 받고, 보조표 키 중복·미결합 금리/수수료·알 수 없는 구간 범주는 오류로 중단하도록 했다. 원본 출력·개인 주석·환경 설치 셀·중복 그림은 공개하지 않는다. 원본 파일은 수정하지 않았다.

## 민감도와 남은 개선

FPI 수익기여 가중치를 0.4/0.5/0.6, 효율 가중치를 0.6/0.5/0.4로 바꾸고 각 경우 전체 표본 중앙값으로 재분류했다. 다른 전처리·피처 스케일은 고정했다. 최신 월 일반 알짜 462/459/458행, 기본 집단과 Jaccard 약 0.9935/1.0000/0.9978이다. 이 좁은 가중치 범위의 안정성만 확인했다. IQR 기준·스케일 범위·수익 산식 변화의 강건성은 검증하지 않았다.

고객 ID·실제 원가·상품 상태를 확보하면 과거 기간에 적합한 기준을 고정해 다음 기간 성과를 확인하고, 캠페인 무작위 대조 실험으로 증분 효과를 검증한다. 현재 실행한 분석을 시간 외 검증이나 A/B 실험으로 표현하지 않는다.
